# CVM++ (Custom Virtual Machine Plus Plus)

CVM++ is a feature-rich, high-performance programming language implemented with a custom Lexer, Parser, Compiler and Stack-based Virtual Machine. It supports complex data types, mixed-type arithmetic, array, string, functions, recursion and bytecode serialization.

---

## 1. Getting Started

### Prerequisites
- C++17 or higher
- CMake (for building)
- PowerShell (for the convenience build script)

### Building the Project
Run the provided build script to compile the `cvm.exe` executable:
```powershell
./build.ps1
```

---

## 2. Running Programs

CVM++ offers 2 modes of operation:

### A. Direct Execution (Interpret)
Run a `.cvm` source file directly:
```powershell
./cvm.exe path/to/file.cvm
```

### B(1). Bytecode Compilation
Compile a source file into a portable binary bytecode format (`.cvmb`):
```powershell
./cvm.exe --compile path/to/file.cvm
```
This will generate a `file.cvmb` without executing it.

### B(2). Bytecode Execution
Run a pre-compiled binary file:
```powershell
./cvm.exe path/to/file.cvmb
```

### Bonus: Debug Mode
Dump the generated bytecode to the terminal and exit:
```powershell
./cvm.exe --debug path/to/file.cvm
```

## 3. Language Syntax & Features

### Data Types
CVM++ supports both explicit typing and type inference:

| Type | Syntax Example | Description |
| :--- | :--- | :--- |
| **Integer** | `integer x = 10;` | 32-bit signed integers |
| **Decimal** | `decimal y = 7.5;` | Double-precision floating point |
| **Character** | `character c = 'A';` | Single ASCII character |
| **String** | `string s = "Hello";` | Sequence of characters |
| **Boolean** | `boolean b = true;` | `true` or `false` |
| **Array** | `array a = [1, "hello", true];` | Dynamic list of mixed values |
| **Inference** | `let z = 50;` | Type determined by initializer |


### Input/Output
- **Input**: integer n=enter();
- **Output**: display(n);
CVM++ supports both display() and displayln() functions for keeping cursor in same line or next line respectively while printing.


### Operators
- **Arithmetic**: `+`, `-`, `*`, `/`, `%` (modulo), `^` (power)
- **Logical**: `AND`, `OR`, `NOT`
- **Comparison**: `==`, `!=`, `<`, `>`, `<=`, `>=`
- **Assignment**: `=`

### Control Flow
#### If-Else
```cvm
if (x > 10) {
    displayln("Large");
} else {
    displayln("Small");
}
```

#### During (While Loop)
```cvm
integer i = 0;
during (i < 5) {
    displayln(i);
    i = i + 1;
}
```

#### For Loop
```cvm
for (integer i from 0 to 10) {
    displayln(i);
}
```

## 4. Arrays and Strings

### Array Operations
- **Literal**: `array arr = [1, "two", 3.0];`
- **Dynamic Creation**: `array a = new array[size];` (initialized to 0)
- **Indexing**: `arr[0] = 100;` (Read/Write)
- **Size**: `size(arr)` returns the number of elements.

### String Operations
- **Literal**: `string s = "CVM++";`
- **Indexing**: `s[0]` returns character at index (Read/Write to local copy).
- **Size**: `size(s)` returns the length of the string.
- **Concatenation**: `+` operator supports `string + string`, `string + char`, and `char + string`.

---

## 5. Functions & Recursion

### Defining Functions
Functions must specify a return type (or `let`) and parameter types.
```cvm
integer factorial(integer n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}
```

### Calling & Recursion
- **Calling**: `integer result = factorial(5);`
- **Recursion**: Fully supported with a managed call stack.
- **Built-in Functions**:
  - `display(val)`: Print value to terminal.
  - `displayln(val)`: Print value with newline.
  - `enter()`: Read input from user (auto-detects integer/decimal/string).

## 6. Project Structure
- `include/`: Header files (.hpp) defining the AST, Lexer, Parser, Compiler, and VM.
- `src/`: Implementation files (.cpp).
- `root folder/`: Sample programs demonstrating language features.
- `Persistence.hpp`: Handles binary serialization of bytecode.
