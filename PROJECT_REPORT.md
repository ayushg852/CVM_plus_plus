# CVM++ Project Report

## 1. Project Overview
CVM++ (Custom Virtual Machine Plus Plus) is a high-performance, stack-based virtual machine and programming language environment. It features a complete pipeline from source code to execution, including a lexer, parser, abstract syntax tree (AST) generator, bytecode compiler, and a robust virtual machine. The language is designed to be expressive, supporting mixed-type arithmetic, dynamic arrays, strings, and recursive functions.

## 2. Language Features

### 2.1 Data Types
CVM++ supports a variety of primitive and complex data types:
- **Integer**: 32-bit signed integers.
- **Decimal**: Double-precision floating-point numbers.
- **Character**: Single ASCII characters.
- **String**: Sequences of characters with support for concatenation and indexing.
- **Boolean**: Logical `true` and `false`.
- **Array**: Dynamic, mixed-type arrays that can store any value type.
- **Type Inference**: Use of the `let` keyword allows the compiler to infer types from initializers.

### 2.2 Control Flow
- **Conditional Statements**: `if-else` blocks for branching logic.
- **Loops**: 
    - `during`: A while-loop construct.
    - `for`: A range-based loop (e.g., `for (integer i from 0 to 10)`).
- **Functions**: Support for named functions with parameter and return type declarations. Full support for **recursion**.

### 2.3 Input/Output
- `display(val)`: Prints a value to the standard output.
- `displayln(val)`: Prints a value followed by a newline.
- `enter()`: Interactively reads input from the user, automatically detecting the type (integer, decimal, or string).

## 3. System Architecture

The CVM++ architecture follows a classic compiler pipeline:

### 3.1 Lexer
The Lexer performs lexical analysis, converting the raw source code into a stream of tokens. It handles whitespace, comments (both single-line and multi-line), and identifies keywords, literals, and operators.

### 3.2 Parser & AST
The Parser consumes the token stream and builds an **Abstract Syntax Tree (AST)**. It uses recursive descent parsing to enforce the language's grammar. The AST represents the hierarchical structure of the program, with nodes for expressions (literals, binary/unary ops, calls) and statements (variable declarations, blocks, loops).

### 3.3 Compiler
The Compiler traverses the AST and generates bytecode for the Custom Virtual Machine. It manages:
- **Constant Pool**: Storage for literal values used in the program.
- **Symbol Table**: Manages scope and variable resolution.
- **Jump Patching**: Handles control flow by calculating relative offsets for jumps in loops and conditionals.

### 3.4 Virtual Machine (VM)
The VM is a stack-based execution engine. It interprets the generated bytecode using an instruction pointer and a value stack. 
- **Stack-based**: Most operations pop operands from the stack and push the result.
- **Managed Memory**: Uses `std::variant` and `shared_ptr` for safe and flexible value handling (including dynamic arrays and strings).
- **Call Stack**: Manages function calls, local variables, and return addresses.

### 3.5 Bytecode & Persistence
CVM++ supports a compiled binary format (`.cvmb`). The `Persistence` module handles the serialization of the bytecode chunk and constant pool, allowing programs to be compiled once and executed multiple times without re-parsing.

## 4. Operational Modes
1. **Interpreter Mode**: Compiles and executes source code in one step.
2. **Compiler Mode**: Compiles source code to a `.cvmb` binary file.
3. **Execution Mode**: Runs a pre-compiled `.cvmb` binary.
4. **Debug Mode**: Disassembles and prints the generated bytecode for inspection.

## 5. Implementation Details
- **Language**: C++17
- **Key Modules**:
    - `Lexer.cpp/hpp`: Tokenization.
    - `Parser.cpp/hpp`: AST generation.
    - `AST.hpp`: AST node definitions and Visitor pattern.
    - `Compiler.cpp/hpp`: Bytecode generation.
    - `VM.cpp/hpp`: Bytecode interpretation.
    - `Chunk.hpp`: Bytecode and constant storage.
    - `Persistence.hpp`: Binary serialization.

## 6. Recent Improvements
- **Build System**: A PowerShell build script (`build.ps1`) was implemented for seamless compilation across environments.
- **Bug Fixes**: 
    - Resolved a critical build error in `AST.hpp` where an undefined `advance` method in `UnaryExpr` prevented successful compilation.
    - Enhanced error reporting in the Parser for better developer feedback.

## 7. Example Programs
The project includes several demonstration scripts:
- `factorial.cvm`: Demonstrates recursion and user input.
- `binary_search.cvm`: Showcases arrays and complex logic.
- `string_demo.cvm`: Illustrates string manipulation and concatenation.
- `tax_calculator.cvm`: Demonstrates decimal arithmetic and conditionals.

## 8. Conclusion
CVM++ provides a robust and flexible platform for learning about compiler design and virtual machine architecture. Its support for modern programming constructs like dynamic arrays and recursion, combined with its ability to serialize bytecode, makes it a powerful educational tool and a capable custom scripting environment.
